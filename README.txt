REALMFALL 7.0 — POLISHED ONLINE CO-OP TANK ROGUELIKE

WHAT IS NEW
- 60-floor campaign across 8 visually distinct regions
- Region-specific palettes, arena decoration and map layouts
- 20 bosses with differentiated attack behavior, phase changes and signature patterns
- 38 build cards across Common/Rare/Epic/Mythic/Legendary/Secret
- 16 active relics with real combat/economy/survival effects
- 8 equipable tactical abilities with cooldowns, energy costs and different playstyles
- Ability Armory in shop floors + inventory equipment screen
- F-key equipped ability, E inventory, Q EMP, R missile, Space dash
- Card/relic synergies such as cannon+loader, missile builds, energy builds, crit builds and shield builds
- Richer boss effects, ability effects, map structures and tank animation polish
- Procedural arena decoration per floor/region
- WebAudio combat/UI feedback for shooting, dash, EMP, missiles, abilities and boss entrances
- Downed/revive co-op, reconnect support, ready-up lobby and 4-player rooms
- Normal / Hard / Nightmare / Endless modes
- Victory/run summary and progression

RUN
1. Install Node.js.
2. Open this folder in a terminal.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

ONLINE
The server must be hosted on a public Node.js-compatible service for friends on different networks to connect.
