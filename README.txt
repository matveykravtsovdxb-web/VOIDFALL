REALMFALL — GitHub Pages version

IMPORTANT:
- The main game is index.html and does NOT require server.js.
- It uses PeerJS for browser-to-browser lobby connections, so it can run from GitHub Pages.
- Upload index.html to the ROOT of your GitHub Pages repository.
- Open the published GitHub Pages URL.
- Create Lobby -> share the 6-character code -> friends choose Join Lobby.

CONTROLS:
WASD / Arrow keys = move
Mouse click = attack
Space = dash
Q = ability

OPTIONAL:
server.js/package.json are included if you later want to use the Node/Socket.IO server version instead.
GitHub Pages itself cannot run server.js.
